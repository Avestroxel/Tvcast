# CastSync Browser Bridge

## دامەزراندن لە Chrome

1. لە لاپتۆپ Chrome بکەرەوە و بچۆ بۆ `chrome://extensions`.
2. **Developer mode** چالاک بکە.
3. **Load unpacked** هەڵبژێرە.
4. ئەم فولدەرە، واتە `chrome-extension`، هەڵبژێرە.
5. پەڕەی CastSync لە لاپتۆپ بکەرەوە، ئایکۆنی Extension ـەکە بکەرەوە و **Connect This CastSync** هەڵبژێرە.
6. پەڕەکە خۆکارانە Refresh دەبێتەوە؛ پاشان **This is my screen** هەڵبژێرە.

Extension ـەکە تەنها لە Chrome ـی لاپتۆپ دادەمەزرێت. لە مۆبایل هیچ Extension ـێک پێویست نییە.

ڕێگەپێدانی سایتەکان پێویستە چونکە Extension ـەکە دەبێت تابی ڕاستەقینە بکاتەوە، کلیک و نووسین و Play/Pause ئەنجام بدات و پێشبینینی شاشە بۆ مۆبایل بنێرێت.

تەنها ئەو ناونیشانی CastSync ـەی بە دەستی خۆت بە **Connect This CastSync** ڕێگەی پێدەدەیت دەتوانێت Extension ـەکە بەکاربهێنێت.
